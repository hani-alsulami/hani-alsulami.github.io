Detection Engineering

Search a malware family, RAT, or offensive tool by name or alias. It cross-references the MITRE ATT&CK techniques that sample is documented to use with matching community Sigma detection rules (surfaced via detection.fyi) and Malpedia profile data — a starting point for how to actually hunt it, not just a name.

Static index, rebuilt weekly by a GitHub Action from public sources — no server, no API keys exposed in the browser. Coverage is technique-based: a rule appears because it detects an ATT&CK technique this malware is documented to use, not because it names the malware directly.
